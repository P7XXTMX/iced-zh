## Bézier tool（贝塞尔工具）

一个类似画图的工具，使用 `Canvas` 部件绘制贝塞尔曲线。

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
  <img src="https://iced.rs/examples/bezier_tool.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package bezier_tool
```
