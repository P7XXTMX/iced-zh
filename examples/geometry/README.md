## Geometry（几何图形）

一个自定义部件，展示如何用 [`iced_wgpu`](../../wgpu) 中的 `Mesh2D` 图元绘制几何图形。

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
  <img src="https://iced.rs/examples/geometry.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package geometry
```
