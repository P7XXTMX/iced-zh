## Arc（圆弧）

一个使用 `Canvas` 部件绘制旋转圆弧的应用程序。

这是针对 https://github.com/iced-rs/iced/pull/1358 的一个简单演示。

__[`main`]__ 文件包含了这个示例的全部代码。

你可以用 `cargo run` 运行它：
```
cargo run --package arc
```
