## Solar system（太阳系）

一个用 `Canvas` 部件绘制的动画太阳系，展示如何组合不同的变换。

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
  <img src="https://iced.rs/examples/solar_system.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package solar_system
```
