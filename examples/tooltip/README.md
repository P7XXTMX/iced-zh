## 工具提示（Tooltip）

一个工具提示。

它根据光标位置，在另一个部件之上显示并定位一个部件。

**[`main`]** 文件包含了这个示例的全部代码。

你可以用 `cargo run` 运行它：
```
cargo run --package tooltip
```
