## Stopwatch（秒表）

一个带有开始/停止和重置按钮的秒表，展示如何监听时间。

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
  <img src="https://iced.rs/examples/stopwatch.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package stopwatch
```
