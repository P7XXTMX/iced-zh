## Pick-list（选择列表）

一个由可选选项组成的下拉列表。

它根据部件在窗口中的位置来显示并定位一个覆盖层。

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
  <img src="https://user-images.githubusercontent.com/518289/87125075-2c232e80-c28a-11ea-95c2-769c610b8843.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package pick_list
```
