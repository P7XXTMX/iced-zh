## Combo-Box（组合框）

一个由可搜索、可选择的选项组成的下拉列表。

它根据部件在窗口中的位置来显示并定位一个覆盖层。

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
    <img src="combobox.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package combo_box
```
