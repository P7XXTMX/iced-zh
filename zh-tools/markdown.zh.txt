## 特性

* 简单易用、开箱即用的 API
* 类型安全的响应式编程模型
* [跨平台支持][Cross-platform support]（Windows、macOS、Linux 和 Web）
* 响应式布局
* 内置部件（包括[文本输入框][text inputs]、[可滚动区域][scrollables]等等！）
* 支持自定义部件（创建你自己的部件！）
* [带有性能指标和时间旅行的调试工具][Debug tooling with performance metrics and time traveling]
* 对异步操作的一等支持（使用 future！）
* 模块化的生态系统，拆分为多个可复用的部分：
  * 一个[与渲染器无关的原生运行时][renderer-agnostic native runtime]，可以集成到已有的系统中
  * 两个内置渲染器，分别基于 [`wgpu`] 和 [`tiny-skia`]
    * [`iced_wgpu`] 支持 Vulkan、Metal 和 DX12
    * [`iced_tiny_skia`] 提供软件渲染作为回退方案
  * 一个[窗口外壳][windowing shell]

__Iced 目前是实验性软件。__ 可以[看看路线图][Take a look at the roadmap]，
也可以[查看 issue 列表][check out the issues]。

## 概览

受 [Elm 架构][The Elm Architecture]的启发，Iced 期望你把用户界面
拆分为四个不同的概念：

* __状态（State）__ —— 应用程序的状态
* __消息（Messages）__ —— 你关心的用户交互或有意义的事件
* __视图逻辑（View logic）__ —— 把__状态__显示为部件的方式，
  这些部件在用户交互时可能产生__消息__
* __更新逻辑（Update logic）__ —— 响应__消息__并更新__状态__的方式

我们可以动手做个东西来看看它是如何工作的！假设我们想要一个简单的计数器，
可以用两个按钮来增加和减少。

我们先为应用程序的__状态__建模：

```rust
#[derive(Default)]
struct Counter {
    value: i32,
}
```

接下来，我们需要定义计数器可能的用户交互：
按钮的按下。这些交互就是我们的__消息__：

```rust
#[derive(Debug, Clone, Copy)]
pub enum Message {
    Increment,
    Decrement,
}
```

现在，让我们在__视图逻辑__中把这些组合起来，
显示出真正的计数器：

```rust
use iced::widget::{button, column, text, Widget};

impl Counter {
    pub fn view(&self) -> impl Widget<Message> {
        // 我们使用一个列：一种简单的垂直布局
        column![
            // 增加按钮。我们让它在被按下时产生一条
            // `Increment` 消息
            button("+").on_press(Message::Increment),

            // 我们在这里显示计数器的值
            text(self.value).size(50),

            // 减少按钮。我们让它在被按下时产生一条
            // `Decrement` 消息
            button("-").on_press(Message::Decrement),
        ]
    }
}
```

最后，我们需要能够在__更新逻辑__中响应产生的__消息__，
并相应地改变__状态__：

```rust
impl Counter {
    // ...

    pub fn update(&mut self, message: Message) {
        match message {
            Message::Increment => {
                self.value += 1;
            }
            Message::Decrement => {
                self.value -= 1;
            }
        }
    }
}
```

这就是全部了！我们刚刚写出了一个完整的用户界面。让我们运行它：

```rust
fn main() -> iced::Result {
    iced::run(Counter::update, Counter::view)
}
```

Iced 会自动：

  1. 取得__视图逻辑__的结果，并对其中的部件进行布局。
  1. 处理来自系统的事件，并为__更新逻辑__产生__消息__。
  1. 绘制得到的用户界面。

阅读[这本书][book]、[文档][documentation]和[示例][examples]以了解更多！

## 实现细节

Iced 最初诞生于一次尝试：把 [Elm] 和 [Elm 架构][The Elm Architecture]的简洁
带入 [Coffee]——我正在开发的一个 2D 游戏库。

这个库的核心是在 2019 年 5 月通过[这个 pull request][this pull request] 实现的。
[第一个 alpha 版本][The first alpha version]最终作为
[一个与渲染器无关的 GUI 库][a renderer-agnostic GUI library]发布。当时这个库不提供渲染器，
并在游戏库 [`ggez`] 之上实现了现在的 [tour 示例][tour example]。

从那以后，重心转向提供一个开箱即用、面向最终用户的 GUI 库，
同时保持生态系统的模块化。

## NixOS

你可以把这个 `shell.nix` 添加到项目中，并通过运行 `nix-shell` 来使用它：

```nix
{ pkgs ? import <nixpkgs> { } }:

let
  dlopenLibraries = with pkgs; [
    libxkbcommon

    # GPU 后端
    vulkan-loader
    # libGL

    # 窗口系统
    wayland
    # xorg.libX11
    # xorg.libXcursor
    # xorg.libXi
  ];
in pkgs.mkShell {
  nativeBuildInputs = with pkgs; [
    cargo
    rustc
  ];

  # 你的项目在构建时链接的其他库，
  # 例如 OpenSSL
  buildInputs = [];

  env.RUSTFLAGS = "-C link-arg=-Wl,-rpath,${pkgs.lib.makeLibraryPath dlopenLibraries}";
}
```

或者，你也可以用这个 `flake.nix` 创建一个开发 shell，通过 `nix develop` 激活：

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    systems.url = "github:nix-systems/default";
  };

  outputs = { nixpkgs, systems, ... }:
    let
      eachSystem = nixpkgs.lib.genAttrs (import systems);
      pkgsFor = nixpkgs.legacyPackages;
    in {
      devShells = eachSystem (system:
        let
          pkgs = pkgsFor.${system};
          dlopenLibraries = with pkgs; [
            libxkbcommon

            # GPU 后端
            vulkan-loader
            # libGL

            # 窗口系统
            wayland
            # xorg.libX11
            # xorg.libXcursor
            # xorg.libXi
          ];
        in {
          default = pkgs.mkShell {
            nativeBuildInputs = with pkgs; [
              cargo
              rustc
            ];

            # 你的项目在构建时链接的其他库，
            # 例如 OpenSSL
            buildInputs = [];

            env.RUSTFLAGS = "-C link-arg=-Wl,-rpath,${nixpkgs.lib.makeLibraryPath dlopenLibraries}";
          };
        });
    };
}
```

## 其他示例（Extras）
还有许多更简单的示例：

- [`bezier_tool`](bezier_tool)：一个类似画图的工具，使用 `Canvas` 部件绘制贝塞尔曲线。
- [`clock`](clock)：一个使用 `Canvas` 部件绘制时钟及其指针来显示当前时间的应用程序。
- [`color_palette`](color_palette)：一个基于用户自定义根颜色的调色板生成器。
- [`counter`](counter)：[`README`](../README.md) 中讲解的经典计数器示例。
- [`custom_widget`](custom_widget)：演示如何构建一个绘制圆形的自定义部件。
- [`download_progress`](download_progress)：一个基本的应用程序，异步下载一个 100 MB 的虚拟文件并跟踪下载进度。
- [`events`](events)：使用条件 `Subscription` 显示的原生事件日志。
- [`geometry`](geometry)：一个自定义部件，展示如何用 [`iced_wgpu`](../wgpu) 中的 `Mesh2D` 图元绘制几何图形。
- [`integration`](integration)：演示如何把 Iced 集成到一个已有的 [`wgpu`] 应用程序中。
- [`pane_grid`](pane_grid)：一个由窗格组成的网格，窗格可以分割、调整大小和重新排列。
- [`pick_list`](pick_list)：一个由可选选项组成的下拉列表。
- [`pokedex`](pokedex)：一个使用 [PokéAPI] 显示随机宝可梦图鉴条目（包括精灵图！）的应用程序。
- [`progress_bar`](progress_bar)：一个简单的进度条，可以用滑块来填充。
- [`scrollable`](scrollable)：展示各种可滚动内容的配置。
- [`sierpinski_triangle`](sierpinski_triangle)：一个[谢尔宾斯基三角形](https://en.wikipedia.org/wiki/Sierpi%C5%84ski_triangle)模拟器，使用 `Canvas` 和 `Slider`。
- [`solar_system`](solar_system)：一个用 `Canvas` 部件绘制的动画太阳系，展示如何组合不同的变换。
- [`stopwatch`](stopwatch)：一个带有开始/停止和重置按钮的秒表，展示如何监听时间。
- [`svg`](svg)：一个利用 `Svg` 部件渲染 [Ghostscript Tiger] 的应用程序。

它们都被打包在各自的 crate 中，因此可以用 `cargo` 运行：
```
cargo run --package <example>
```

@@@ examples/pane_grid/README.md
## Pane grid（窗格网格）

一个由窗格组成的网格，窗格可以分割、调整大小和重新排列。

这个示例展示了 `PaneGrid` 部件，它的特性包括：

* 垂直和水平分割
* 跟踪最后一个活动窗格
* 用鼠标调整大小
* 通过拖放重新排列窗格
* 支持快捷键
* 可配置的修饰键
* 以编程方式执行操作的 API（`split`、`swap`、`resize` 等）

__[`main`]__ 文件包含了这个示例的全部代码。

<div align="center">
  <img src="https://iced.rs/examples/pane_grid.gif">
</div>

你可以用 `cargo run` 运行它：
```
cargo run --package pane_grid
```

@@@ examples/websocket/README.md
## Websocket

一个简单的示例，它与一个回显服务器保持 WebSocket 连接。

这个示例由 3 个模块组成：
- [`main`] 包含 `Application` 逻辑。
- [`echo`] 使用 `async-tungstenite` 实现了一个连接 [`echo::server`] 的 WebSocket 客户端。
- [`echo::server`] 使用 `warp` 实现了一个简单的 WebSocket 回显服务器。

你可以用 `cargo run` 运行它：
```
cargo run --package websocket
```
